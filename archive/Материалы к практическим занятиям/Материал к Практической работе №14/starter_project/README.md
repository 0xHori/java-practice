# Практическая работа 11

Автоматические тесты, Maven и проверка граничных условий.

Исходный проект намеренно неполный. TODO обозначают места, которые необходимо завершить. До начала работы изучите постановку задачи, Activity-диаграмму и диаграмму классов. Производственный код расположен в `src/main/java`, тесты — в `src/test/java`.

Быстрая проверка production-кода без Maven

```bash
./run_selfcheck.sh
```

Полный запуск JUnit-тестов после выполнения задания

```bash
mvn test
```

Тестовые методы студент дополняет самостоятельно. Наличие успешной сборки не заменяет объяснение выбранных граничных значений на защите.
